# Welcome to OpenMOQ

We have lots of great repos for you to explore, below is a short guide what you can find here.  
For more information on OpenMOQ please visit our website: [openmoq.org](openmoq.org)  
If you have any questions or comments please contact us at support@openmoq.org or reach out the contributors directly.

## Relay

- [moqx](https://github.com/openmoq/moqx) - The OpenMOQ relay
  - [moxygen](https://github.com/openmoq/moxygen) - OpenMOQ moxygen fork (consumed by moqx)
  - [picoquic](https://github.com/openmoq/picoquic) - OpenMOQ picoquic fork (consumed by moqx)

## Client implementations

- [FFmpeg](https://github.com/openmoq/FFmpeg) - OpenMOQ fork of FFmpeg
- [openmoq-plugin](https://github.com/openmoq/openmoq-plugin) - OpenMOQ OBS Studio plugin

## Client libraries

- [moq5](https://github.com/openmoq/moq5) - Sans-I/O MoQ Transport library in C
- [moq-playa](https://github.com/openmoq/moq-playa) - MOQ reference implementation in TypeScript
- [aiomoqt](https://github.com/openmoq/aiomoqt) - OpenMOQ aiomoqt fork - Python MOQT client/server package built on aiopquic
  - [aioquic](https://github.com/openmoq/aiopquic) - OpenMOQ aiopquic fork - Python/Cython binding to picoquic

## Test tools

- [moq-relay-test](https://github.com/openmoq/moq-relay-test) - A tool for interop testing of MOQT relays
